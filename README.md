## Online Store Sales & Profitability Analysis

This project analyzes revenue, cost, refunds, and profitability
using SQL Server and Tableau.

### Key Features
- Data modeling using SQL views
- Product- and user-level profitability analysis
- Refund impact analysis
- Interactive Tableau dashboard

### Tools Used
- SQL Server (Views, Joins, Aggregations)
- Tableau (KPIs, Trends, Filters)
